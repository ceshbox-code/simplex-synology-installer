Настройка Планировщика задач DSM
  1. Откройте DSM → Панель управления → Планировщик задач.
  2. Нажмите Создать → Запланированная задача → Определённая пользователем команда.
  3. Вкладка Общие:
    • Задача: SimpleX Backup
    • Пользователь: root
    • Включено: ✔
  4. Вкладка Расписание:
    • Выполнять: Ежедневно
    • Время: 03:00
  5. Вкладка Параметры задачи:
    • Команда: /volume1/docker/simplex/simplex-backup.sh
  6. Нажмите OK для сохранения.
  7. Проверка: выделите задачу → Запустить. Файл появится в /volume1/docker/simplex/backups/.
💡 Скрипт автоматически удаляет копии старше 14 дней. Для изменения срока отредактируйте -mtime +14 в файле simplex-backup.sh.
⚠️ Храните хотя бы одну резервную копию на внешнем носителе или в облачном хранилище отдельно от NAS.

Резервное копирование

Настройка Планировщика задач DSM
  1. Откройте DSM → Панель управления → Планировщик задач.
  2. Нажмите Создать → Запланированная задача → Определённая пользователем команда.
  3. Вкладка Общие:
    • Задача: SimpleX Backup
    • Пользователь: root
    • Включено: ✔
  4. Вкладка Расписание:
    • Выполнять: Ежедневно
    • Время: 03:00 (ночью, минимальная нагрузка)
  5. Вкладка Параметры задачи:
    • Команда: /volume1/docker/simplex/simplex-backup.sh
  6. Нажмите OK для сохранения.
  7. Для проверки: выделите задачу в списке → Запустить. Убедитесь, что в папке /volume1/docker/simplex/backups/ появился файл simplex-backup-YYYYMMDD_HHMMSS.tar.gz.
💡 Скрипт автоматически удаляет резервные копии старше 14 дней. Для изменения срока хранения отредактируйте параметр -mtime +14 в файле simplex-backup.sh.
⚠️ Храните хотя бы одну резервную копию на внешнем носителе или в облачном хранилище отдельно от NAS.
